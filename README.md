## 🚀 Proyectos destacados e impacto

### Sistema Avanzado de Seguridad, Roles y Gestión de Usuarios

Desarrollo de un ecosistema robusto y dockerizado para el control de accesos, gestión de identidades y administración de módulos dinámicos. El sistema separa lógicamente las capas de control mediante un esquema granular que distingue entre configuraciones críticas de la plataforma y permisos operativos cotidianos.

*   **Arquitectura de Permisos Dual:** Implementación de un backend especializado con gestión independiente de **Permisos de Sistema** (control de menús y estructuras de desarrollo) y **Permisos Generales** asignados a los usuarios.
*   **Gestión Dinámica de Módulos:** Interfaz administrativa dedicada a la creación, categorización y aprovisionamiento de nuevos módulos y claves de permisos directamente integrables con el backend en tiempo de ejecución.
*   **Seguridad y Auditoría:** Módulo de bitácora integrada (`UserLog`) para el rastreo y auditoría completa de operaciones de negocio, junto con herramientas de restablecimiento de credenciales y asignación masiva de roles.
*   **Stack Técnico Utilizado:** Docker, CodeIgniter 4 (CI4), PostgreSQL, Redis para caché/sesiones, HTML5 y JavaScript Minificado para optimización de carga en el cliente.

### Sistema de Mensajería y Gestión Documental "Cero Papel"

Solución de comunicación interna orientada a la transformación digital y la sustentabilidad institucional mediante la eliminación del soporte físico.

*   **Intercambio en Tiempo Real:** Envío y recepción de mensajería local entre dependencias, áreas y usuarios con confirmación de lectura.
*   **Gestión de Archivos Adjuntos:** Repositorio digital integrado para la transferencia y resguardo seguro de documentos institucionales vinculados a las comunicaciones.


### Sistema Integral de Gestión Catastral

Plataforma web con mapas interactivos, capas georreferenciadas y descarga de fichas urbanas mediante códigos QR dinámicos. Integra tecnologías de geolocalización como OpenLayers y Leaflet.

**Impacto reportado:** reducción del 60 % en los tiempos de atención ciudadana.

### Automatización de scripts con IA

Integración de APIs de inteligencia artificial en Google Apps Script para agilizar el análisis de código, apoyar la refactorización y automatizar auditorías de scripts.

### Sistema de control de asistencia y reportes

Aplicación de escritorio con reportería avanzada en JasperReports, diseñada para optimizar procesos de control de asistencia y gestión de recursos humanos.
